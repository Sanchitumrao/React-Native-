## 🎯 Repository Goal

This repository is my personal **React Native learning, coding, and revision handbook**.

It is designed for:

* Quick revision of important concepts
* Concise explanations and practical examples
* Reusable code snippets and patterns
* Useful commands and debugging solutions
* Learning through real projects
* Continuously documenting concepts while building applications

# ⚡ Quick Reference

## Common React Native Commands

```bash
# Start Metro
npm start

# Install dependencies
npm install

# Run Android
npm run android

# Run iOS
npm run ios

# Clear Metro cache
npx react-native start --reset-cache
```

## Frequently Used Concepts

| Concept        | Purpose                             |
| -------------- | ----------------------------------- |
| `View`         | Container                           |
| `Text`         | Display text                        |
| `TextInput`    | User input                          |
| `FlatList`     | Efficient lists                     |
| `useState`     | Local state                         |
| `useEffect`    | Side effects                        |
| `useContext`   | Shared context                      |
| Fetch / Axios  | API requests                        |
| JWT            | Token-based authentication          |
| Secure Storage | Sensitive local data                |
| AsyncStorage   | Persistent non-sensitive local data |
