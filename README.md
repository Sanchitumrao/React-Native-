# ⚡ Quick Reference

## Common React Native Commands

```bash
# Start Metro
npm start

# Install dependencies
npm install

# Run Android
npm run android

# Run iOS
npm run ios

# Clear Metro cache
npx react-native start --reset-cache
```
## Common Expo Commands

```bash
# Start Expo
npx expo start

# Start Expo and clear Metro cache.
npx expo start -c

# Prefer Expo's installer for Expo/React Native packages:
npx expo install package-name

# Checks your Expo project for compatibility/problems.
npx expo-doctor

```
